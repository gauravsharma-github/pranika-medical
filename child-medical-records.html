How to add your child's details & PDF links
  1. Open this HTML file in any text editor (Notepad, VS Code…). Everything you edit lives in one place — scroll to the banner that says STEP 1 — YOUR CHILD'S DETAILS.
  2. Step 1: fill in the CHILD block — name, date of birth (YYYY-MM-DD), blood group, allergies, medications, care team (pediatrician, neurologist, therapy centre) and emergency contacts. Delete the sample values.
  3. Step 2 — Medical history: in the RECORDS block, each { … } is one record. Copy-paste a block to add a new entry. category must be one of: Vaccination, Doctor Visit, Neurology, Therapy Assessment, Lab Report, Prescription, Hospitalization, Other. Tabs appear automatically for categories that have at least one entry.
  4. Step 3 — Daily therapy logs: in the THERAPY_LOGS block, each { … } is one session. therapy must be one of: Speech Therapy, Occupational Therapy, Physiotherapy, Behavioural Therapy, Special Education, Other. The driveLink here is optional — use it only when the centre shares a daily report PDF.
  5. Google Drive link: in Drive, right-click the PDF → Share → Copy link, then paste it into the record's driveLink line, replacing PASTE_YOUR_GOOGLE_DRIVE_LINK_HERE (keep the quotes).
  6. Sharing setting: if only you will open this page while signed in to your own Google account, "Restricted" is fine. If family members should view the PDFs too, set the file to Anyone with the link → Viewer.
  7. Save the file and refresh this page in your browser — done.
🔒 This file contains personal medical information — keep it on your own device or private storage. Don't upload it to a public website.
