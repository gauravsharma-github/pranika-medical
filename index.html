How to add your child's details, PDF links & the tracker sheet
  1. Open this HTML file in any text editor (Notepad, VS Code…). Everything you edit lives in one place - scroll to the banner that says STEP 1 - YOUR CHILD'S DETAILS.
  2. Step 1: fill in the CHILD block - name, date of birth (YYYY-MM-DD), blood group, medications, care team (pediatrician, neurologist, therapy centre) and emergency contacts.
  3. Step 2 - Medical history: in the RECORDS block, each { … } is one record. Copy-paste a block to add a new entry. category must be one of: Vaccination, Doctor Visit, Neurology, Therapy Assessment, Lab Report, Prescription, Hospitalization, Other. Tabs appear automatically for categories that have at least one entry.
  4. Step 3 - Therapy Tracker sheet: paste your Google Sheet's link into TRACKER.sheetLink (in Sheets: Share → Copy link). A green bar then appears above the sessions with Quick view (opens the sheet in a popup here) and Open sheet ↗. Sharing: since the sheet holds detailed session data, the safest option is to Share it with specific people (family / therapist email IDs) as Viewer - they'll need to be signed in to Google for Quick view to load. Anyone with the link → Viewer also works and is easier for relatives, but then anyone who gets hold of the link can read it.
  5. Step 3 - Session entries: in the THERAPY_LOGS block, each { … } is one session, using the same fields as the sheet's Daily Log tab: date (required), therapyType, sessionDuration, mood (Very good / Good / Okay / Difficult), promptingNeeded (None / Minimal / Moderate / A lot), challengingBehaviour (short text, or null), mainSkillsWorkedOn / instructionsFollowed / communicationWordsUsed (a ["list", "of", "items"] shows as chips; a plain "sentence" shows as text), foodSnack, water, bathroom, otherActivities, and therapistNotes / parentNotes (use \n inside the text for line breaks). Any field set to null or "" is hidden on the page. You can also add an optional driveLink to any entry to attach a daily report PDF.
  6. Google Drive link (records): in Drive, right-click the PDF → Share → Copy link, then paste it into the record's driveLink line, replacing PASTE_YOUR_GOOGLE_DRIVE_LINK_HERE (keep the quotes).
  7. PDF sharing setting: if only you will open this page while signed in to your own Google account, "Restricted" is fine. If family members should view the PDFs too, share those files the same way as the sheet.
  8. Save the file and refresh this page in your browser - done.
